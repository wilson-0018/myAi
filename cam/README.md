# CAM智能行业洞察平台

这是根据 `CAM智能行业洞察平台 - Codex开发设计任务说明手册 V1.0.md` 搭建的 Next.js MVP。

## 当前已实现

- 首页沉浸式总览：Knowledge Hub、AI Native Team、CIS Liquid Core、状态栏。
- 行业知识情报中心：看趋势、看用户、看竞争、看自己四个入口和知识卡搜索。
- AI原生行业专家团队：7个Agent卡片、运行状态、模拟推理过程与结论。
- 洞察执行驾驶舱：报告看板、建议采纳/修改/驳回、OKR草案、任务卡、知识回写。
- Mock 数据层和 TypeScript 类型定义。

## 运行

```bash
npm install
npm run dev
```

默认访问：

```text
http://localhost:3000
```
