# Week of Dinners — prototype

Static English prototype for constrained weekly dinner planning.

**Flow:** Plan dinners (budget + allergies + kitchen gear + fridge/pantry) → Mon–Sun week plan → grouped shopping list with **Copy list** / **Share**.

Fake menus only. No login, no backend, no calories, no medical claims, no recipe community.

> Prototype for feedback · fake menus · not medical advice
